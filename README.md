### Hey, I'm Vincent.

I'm a **UX/UI product designer based in São Paulo, Brazil**, with 5+ years creating web and mobile products. I work across usability, design systems, and data-informed decisions — and I like taking ideas beyond the mockup.

Here you'll find the things I build: native macOS tools, reusable design assets, and experiments that turn a small frustration into something useful.

### A few things I've made

**[Squishy · Media Manager ↗](https://github.com/vincent-caetano/Squishy-Media-Manager)**<br />
A native macOS tool for converting and compressing video, audio, and images. Drop in your files, choose an output, and let the queue do the work.<br />
<sub>Swift · macOS · FFmpeg</sub>

**[Soundboard for macOS ↗](https://github.com/vincent-caetano/soundboard-for-macos)**<br />
A menu bar soundboard with global hotkeys, waveform trimming, and audio routing. Built for playing sounds without interrupting what you're doing.<br />
<sub>SwiftUI · AVFoundation · CoreAudio</sub>

**[Brazilian State Flags ↗](https://github.com/vincent-caetano/tweemoji-brazil-state-flags)**<br />
27 Twemoji-inspired Brazilian state flags, with editable SVGs, transparent PNGs, typed metadata, and React Native examples.<br />
<sub>Design assets · SVG · React Native</sub>
